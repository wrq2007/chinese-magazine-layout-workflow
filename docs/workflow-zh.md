# 排版工作流说明（给自己看）

这份说明是"换个对话也能接着干"的交接稿。真正干活时，**新开一个对话、把项目目录指到 `E:\YOUR_PROJECT` 就行**——同目录下的 `AGENTS.md` 会被自动读到。

## 开新对话时的开场话术（复制即用）

```
这是我的杂志项目（E:\YOUR_PROJECT）。请先读 AGENTS.md 和
~/.codex/skills/layout-qc/references/mistakes-log.md，
然后按我下面的需求排版。
```

- **文本只复制粘贴**：正文由脚本从源文件读入、原样流入排版，**不增、不删、不改任何字符**（含标点、空格、数字、`&` 之类的符号）；需要改内容会先问你。

## 每次做一件作品，你只需要给三样

1. **文案**：docx / md / txt 的路径（我直接读文件，不手打）
2. **图片**：一张或多张的路径
3. **一句需求**：开本、页数、想突出什么（没头绪时我会按内容量给建议）

不确定的地方我会先问一句再动手（哪张是主图、哪段当标题、要不要页码），避免返工。

## 我会交付什么

| 产物 | 说明 |
| --- | --- |
| 印刷 PDF | CMYK + 3mm 出血，TrimBox = 成品尺寸，字体已嵌入 |
| .indd 源文件 | 可继续编辑，色板/样式/坐标都在 |
| 300dpi 预览图 | 跨页拼图，用于审样（不是 150dpi 的糊图） |
| 局部放大图 | 标题区/正文/署名区 100% 截图，看字体细节 |
| 验收报告 | 尺寸、出血、内嵌字体、对比度、行宽、避头尾（文本不做逐字比对，改由"只复制粘贴"这一条守住） |
