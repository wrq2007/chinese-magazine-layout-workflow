# 排版工作流说明（给自己看）

这份说明是"换个对话也能接着干"的交接稿。真正干活时，**新开一个对话、把项目目录指到 `E:\YOUR_PROJECT` 就行**——同目录下的 `AGENTS.md` 会被自动读到。

## 开新对话时的开场话术（复制即用）

```
这是我的杂志项目（E:\YOUR_PROJECT）。请先读 AGENTS.md 和
~/.codex/skills/layout-qc/references/mistakes-brief.md，
然后按我下面的需求排版。
```

## 每次做一件作品，你只需要给三样

1. **文案**：docx / md / txt 的路径（我直接读文件，不手打）
2. **图片**：一张或多张的路径
3. **一句需求**：开本、页数、想突出什么（没头绪时我会按内容量给建议）

不确定的地方我会先问一句再动手（哪张是主图、哪段当标题、署名放文首还是文末），避免返工。

> 开本/出血/版心/字号这些规格由 skill `cng-magazine-layout` 提供，**你不必每次重讲**；
> 规格要改就说一句，我改规格文件、全篇统一。

## 我会交付什么

| 产物 | 说明 |
| --- | --- |
| 印刷 PDF | CMYK + 3mm 出血，TrimBox = 成品尺寸，字体已嵌入 |
| .indd 源文件 | 可继续编辑，色板/样式/坐标都在 |

**就这两件。** 预览图、联系表、局部放大图都是核查过程中的临时件，用完就清掉，不留在交付目录里
（需要看图时临时生成到 `_build`，核对完删）。

## 验收报告里会有什么

一条命令跑完十项，逐项给实测值与判定（三档：合格 / 注意 / 需处理）：

| 项 | 判据 |
| --- | --- |
| 页面盒 / 出血 / 图像 DPI | TrimBox = 成品尺寸；四边出血 3mm；位图 ≥300dpi |
| 实际边距（墨迹反推） | 不小于版心要求 |
| 内嵌字体 | 100% 内嵌 |
| 装饰元素一致性 | 同类装饰同规格 |
| 孤字成行 | 无段落以 1–2 字收尾 |
| 总墨量 TAC | 铜版纸 300%；>300% 记"贴线"，>330% 或成片 >2% 判不合格 |
| 文字墨色色版构成 | 不许四色黑；反白/浅色小字不许用多色版叠浅色 |
| 输出意图 / 色彩管理 | 必须有 /OutputIntent 或内嵌 ICC |
| 图注：对比度/残字/间距 | 对比度 ≥4.5:1；末行不许剩孤字或单个西文词；间距离散 ≤0.5mm |
| 文字保真 | 从 PDF 抽字符与源文对照 |

**文本仍然只复制粘贴，不改一个字**：正文由脚本从源文件读入、原样流入排版，
不增、不删、不改任何字符（含标点、空格、数字、`&` 之类的符号）；需要改内容会先问你。
守住这条不变式，就不需要事后逐字比对。
