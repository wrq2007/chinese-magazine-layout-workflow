# 杂志排版项目指令

> 这份文件给"接手本项目的 Codex 会话"看。工作流程与规则都在这里，不必依赖历史对话。

## 项目规格（每一件成品都按此执行）

> **规格以 skill `cng-magazine-layout` 为准**（有《中国国家地理》官方刊例做来源）。规格还可能变，**不必纠结数值，重点管内容**。

- 开本 **185×260mm**，**出血 3mm**，**四色胶装**，**175 线**
- 版心 **上 18 / 下 22 / 内 20 / 外 16 mm**（149×220mm）；基准 **6 栏**（栏宽 19 + 栏距 7）
- 正文 **9pt / 14pt**；图注 8.5pt；页码 7.5pt；素材按 **350dpi** 备料（300dpi 是广告最低交付线）
- 色彩：CMYK，总墨量 TAC ≤300%（涂布纸）；正文与小字用**单色黑 K100**，不用四色黑；深底白字字号 ≥10pt
- 交付**两件**：**印刷 PDF**（CMYK + 3mm 出血，TrimBox 必须等于成品尺寸）+ **可编辑 .indd**。
  预览图/联系表/局部放大图只是核查过程中的临时件，需看图时生成到 `_build`，核对完清掉（见第 7 条）

## 与用户协作的硬性偏好

1. 全程**简体中文**、结论先行。
2. 命令可直接执行；但**删除/覆盖/杀进程**等有风险操作先征得确认。
3. **不做纸面宣称**：任何交付前必须用真实产出物验证并给出证据（像素/毫米/对比度/内嵌字体），做不到就明确说未完成。
4. **文本只复制粘贴，不改一个字**：正文一律由脚本从源文件读入、原样流入排版，
   **不增加、不删除、不修改任何字符**（含标点、空格、数字、`&` 这类特殊符号）。
   曾被坑过两次：漏掉「动**&**静」的 &、把作者写的逗号擅自改成顿号。
   **不需要事后逐字比对——守住这条不变式即可**。
   （若确实要核对，走 `check-text-fidelity.py` 的 PDF 抽文，0.2 秒出字符级结论；
   **绝不用视觉模型读字**，见第 6 条。）
5. **任何内容层面的改动，先问用户**再看要不要改。
6. **最后复核不许用视觉模型核对文字**（2026-09 用户定的规矩）：图片送进模型前必然被降采样，
   小字读数不可信——实测把署名「翟翊翔」读成「曹玥玥」、把图注「nomadict」读成「nomadicst」。
   - 文字一致性只走一条路：**从 PDF 抽字符**与源文对照
     （`layout-qc/scripts/check-text-fidelity.py <成品.pdf> <源文...>`）。
   - 视觉模型只保留两个用途：**描述"看到了哪些元素"**、**判断整体观感与结构**（留白、层级、元素是否被压/越界）。
     问它问题时**不要让它抄字**。
   - 几何量（比例、留白、边界）一律程序化扫描，不问模型。
7. **交付只留两件**（2026-09-19 用户定的规矩）：输出目录里**只保留 `.indd` 工程文件和印刷用 `.pdf`**。
   **不再输出**预览图、联系表、局部放大图——它们只是核查过程中的临时件，
   用完就清理，不要留在交付目录里。（需要看图时临时生成到 `_build`，核对完删掉。）
8. **图注体例**：源文没写图注的图，**不要自己编**；确需补写要先把草稿交给用户确认。
   排版规范：8.5pt 灰字、与图同栏宽（图太窄时可放宽到能容一行，避免折成细条）、
   图下 3–4mm、左缘对齐图左缘、与图同页。
9. **署名位置看文体**（2026-09-19 用户定的规矩）：
   - **正式文章**（特稿、教学稿、报道）→ 署名在**文首**，紧跟标题下方、与标题同一条左轴；
     姓名与班级/单位分开设，拉开大小层级。**不要放文末。**
   - **序、前言、跋、编后记**这类 → 才用文末三级递减落款（《序言》那篇的格式）。
   - 只搬位置、不加字：不要擅自加"文 /""◎"这类前缀——要加先问用户。
10. **导出必须显式指定 CMYK 目标配置文件**（2026-09-19 踩坑）：`pdfDestinationProfile` 是
    **应用级偏好**，不写就沿用上一次的。本机默认落在 **Japan Color 2001 Coated（墨量上限 350%）**，
    照那样导，照片最大总墨量会冲到 350%+，**超出涂布纸/铜版纸 300% 的安全线**，而常规检查全绿看不出来。
    - 涂布纸（铜版纸）→ `U.S. Web Coated (SWOP) v2`（上限 300%）；需要 330% 时用 `Coated FOGRA39`。
    - 导完把原值还原，别污染其它文档的导出偏好。
    - 交付前必须跑 `layout-qc/scripts/check-tac.py` 量实际 TAC（三档：**>330% 或超 300% 像素 >2% → 不合格；
      300%–330% → `[注意] 贴线`，说明"没越线不等于有余量"**）。
    - **`pdfDestinationProfile` 只管转换、不会写进文件**：交付前还要跑 `check-output-intent.py`，
      确认 `/OutputIntent` 或内嵌 ICC 存在；没有就把导出改成 PDF/X-4（或至少勾"包含输出意图"）。

## 视觉工作由谁做（2026-09-20 交接）

> 2026-09-20 起不再调用 DeepSeek Harness（dsh）。**它原来承担的视觉工作整体交给 Codex。**
> 交接清单（逐项对应，不丢能力）：

| 原来 dsh 做的 | 现在谁做 | 具体怎么落地 |
| --- | --- | --- |
| 看成品图、判断留白与结构是否成立 | **Codex** | 直接看导出的预览图；观感、层次、重心、密度归眼睛 |
| 判断字体形态（衬线/无衬线、字重） | **Codex + 脚本** | **优先查字体名**（`list-pdf-fonts.ps1`）——比"看图猜"准；实测看图猜字体报错过 |
| 图像理解（照片里是什么、能不能当底图） | **Codex** | 看图 + 脚本量明暗跨度/保留度（同口径比较候选底图） |
| 出海报文案、署名方案、标题变体 | **Codex** | 语言模型本职，本来后半段已经是 Codex 在做 |
| 独立复核"是否真的改到位" | **冷启动复核子代理** | 零上下文派生，用另一条技术路线自己写量测（见下面第 4 步） |
| 审美第二意见（另一套权重） | **本地 qwen** | `ask-local-model.py`，本地零费用 |

**交接时不能丢的三条边界**（这几条和"换谁做"无关，永远成立）：

1. **看图不读字**。图片进模型前必被降采样，小字读数不可信；文字一致性只走 PDF 抽字符。
2. **看图不量几何**。实测：在 200dpi 跨页预览上，我肉眼以为右页首行快贴到裁切边，
   实测是距上切口 26.5mm——**观感归眼睛，毫米归脚本**。
3. **看图的结论必须能被复算**。凡是"我说这里不对"的，都要给出毫米/像素/dpi/色值证据；
   给不出就明说这是主观判断。

⚠️ 另有一处**能力没有交接、而是转移**：dsh 的"第二个运行体"属性（不同工具链的独立性）
不再由 dsh 提供，改由**冷启动子代理**提供（零上下文 + 不读历次意见 + 自己写量测）。
两者走同一个 API key，所以这不是省钱动作，是减少活动部件。

### 排版完成后的复核流程（2026-09-20 改版）

**第 0 步（排版之前）：文字审计**——查错别字、语法、标点、用词。

```bash
python layout-qc/scripts/audit-text.py <源文.md>       # 本地模型出初筛，0 费用
```

分工：**本地 qwen 出初筛 → Codex 逐条核实与过滤 → 输出成表给用户确认 → 用户点头才改**。
理由：这是"读文字找问题"，不碰几何、不碰 API，正是本地模型的强项。
⚠️ 模型报出来的**未经核实不得采信**（它会误报口语化表达）；确认后的改动要同步回源文，
否则下次从源文重建会把修改冲掉。

1. **Codex 初次排版完成**（自己先跑一遍 `qc-all`，不合格项自己改掉，不要带着问题去复核）
2. → **交本地 qwen 审一次**：脚本 `E:\杂志\_qwen\ask-qwen.py`（llama-server @127.0.0.1:8080，
   多模态）。调用时会自动带上 `_qwen\brief.md`（前情提要）与 `_qwen\memory.md`（长期记忆），
   所以它记得规格、记得"页码不需要"这类已定事项，不会重复提。
3. → **Codex 按意见修改**
4. → **交冷启动复核子代理"独立复核"**（零上下文，**不回调 qwen**）：
   写一份盲审任务书放 `work\<NN>-<篇名>\`，用 `fork_turns="none"` 派生子代理去执行。
   任务书里必须有三条硬约束：**不许读 `_qwen\` 的意见目录**、**不许调用本项目现成质检脚本**
   （要它自己写量测）、**不许用模型读图核对文字**。
   ⚠️ 它报的每个数值，**Codex 要自己复算一遍再采信**——实测它也会算错。

> 2026-09-20 之前第 4 步是"交另一个外部工具链复核"。做过一次同成品同任务书的 A/B：

## 与 InDesign 交互的要点（血泪版）

- 标尺单位设为 POINTS，坐标用 `mm × 2.8346`；**字号/行距也跟随标尺单位**（设成毫米会让 33pt 变 33mm → 文字溢出消失）
- 母版必须逐页 `appliedMaster` 才会出现页码
- 导出 PDF 时**不要传预设**（预设会覆盖 `useDocumentBleedWithPDF`，导致 0 出血）
- JPG 导出忽略 `pageString`：一次导整本，"文件名 + 页码"
- 只操作自己打 `label` 的文档；收工关闭自己并恢复原置前文档（并行安全）
- 脚本含中文时必须存 **UTF-8 with BOM**，否则 PowerShell 5.1 按 ANSI 解析报语法错

## 中文排印底线（每次自动执行，不必用户交代）

- 行宽 **25–35 字/行**（特稿两栏约 21 字/行亦可）；正文 9pt（杂志常规）到 11pt（书籍散文）；反白额外 +0.5–1pt
- 小字不用 Light/Thin；**深底白字 ≥10pt**，9pt 以下不反白
- 数字与西文换 Times 类西文字体（比中文小 0.5pt），`&` 不按西文处理
- 避头尾逐行校验；署名三级递减（姓名 → 单位职务 → 班级日期），右对齐
- 图作背景时：模糊 + 渐变遮罩（**方向与照片明暗相反**）+ 自动校准到对比度 ≥4.5:1
- 内容层细则（标题不拆行、图注与图同页、孤字成行、标点全角、年代写法统一等）见
  `~/.codex/skills/magazine-layout/references/text-rules.md`
