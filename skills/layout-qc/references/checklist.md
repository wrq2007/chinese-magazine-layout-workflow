# 交付前检查清单

按成品类型取用，不必逐条机械执行；发现与本次任务无关的项就跳过。

## 通用

- 像素尺寸与目标物理尺寸对得上（DPI 反推），做印刷就核对到毫米。
- 分辨率：印刷图像 ≥ 300 ppi（实际尺寸下）；大尺寸海报 ≥ 150 ppi 可接受。检查位图是否被放大使用。
- 文字是否被裁切、压边、溢出文本框；文本框剩余容量是否为负。
- 中英文混排：数字/西文与汉字之间的间距是否被手动加空格搞乱；标点是否溢出边界。
- 颜色模式：印刷用 CMYK，屏幕交付用 RGB；深色大面积四色黑是否超标（总墨量）。
- 缺失链接的图片、缺失字体、未嵌入的字体（PDF 导出时勾选嵌入子集）。
- 导出件命名与版本号，避免覆盖旧稿。

## 单页成品（海报、单页）

- 出血 3mm（或印厂要求值）；重要内容距裁切线 ≥ 5mm。
- 视觉重心位置与留白比例符合设计意图（用像素量，不靠肉眼印象）。
- 色块边界是否与页面边缘平行、是否有 1px 级的错位。

## 多页成品（杂志、画册）

- 版心（左右边界、上下基线）逐页一致；用逐页量测的文本包围盒逐页比对。
- 跨页图出血连续，中缝处无白边。
- 页码、页眉、页脚位置一致；目录页码与内文实际页码一致。
- 单页起排与跨页起排的选择是否符合阅读节奏（重要文章、专题大图）。
- 文章首末页的断行、孤行寡行、图片与图注是否同页。
- 章节切换处：空页、隔页、页序奇偶是否符合装订要求。

## 常见事故（按发生频率）

1. 页面单位错（毫米当磅用），页面尺寸整体差 2.83 倍，导出件大得离谱。
2. 字体样式用「家族名」而非「家族名\t样式名」设置，导致字体未生效或报错。
3. 装了新字体但排版软件没重启，字体列表里看不到，回退成默认字体。
4. 导出分辨率被换算：导出件像素数与预期差 2.83 倍或 3.94 倍。
5. 视觉模型把成品比例说错，导致误判"排版失衡"。比例永远用像素量。
