# 中文地理人文杂志排版（《中国国家地理》体系）

目标读者是中高端大众，阅读方式是"翻图 + 读故事"。整套体系的核心不是装饰，而是**用图片承担一半以上的信息量，用严格的栅格与样式把这些图片组织成可读、可归档、可批量复用的刊物**。

## 先定这 6 个默认值

除非用户另有要求，直接采用（数值来源与推导见 `references/production-specs.md`）：

| 项 | 默认值 |
|---|---|
| 开本 | 185（宽）× 260（高）mm，出血四边 3mm |
| 装订 | 四色胶装；页数取 16 的倍数（128 / 144 / 160） |
| 版心 | 上 18 / 下 22 / 内 20 / 外 16 mm → 149×220mm |
| 栅格 | 基准 6 栏：栏宽 19 + 栏距 7（19×6+7×5=149） |
| 正文 | 9pt / 14pt，首行缩进 2 字；三栏 45mm 或特稿两栏 71mm |
| 图片 | 印刷线数 175，素材按 **350dpi** 备料，按最终摆放尺寸算像素 |

## 工作流

1. **定骨架**：先写"页数分配表"（栏目 × 页数 × 图量），再动排版软件。骨架见 `references/issue-anatomy.md`；里面的栏目序列决定了广告位和专题节奏，改结构比改细节便宜得多。
2. **建样式与母版**：在 InDesign 里一次建好段落样式（正文 / 导语 / 一级标题 / 二级标题 / 图注 / 页眉 / 页码）、对象样式、6 栏网格母版、目录母版、专题跨页母版、广告位母版。之后每一期只填空，不动样式。
3. **图片先过关**：按 `references/production-specs.md` 的像素表验收；缺像素、缺出血、色域不符的图在排版前退回，不要"先排上再说"。
4. **排正文与图**：整版/跨页图先落位，再分栏排文字；图注、撰文/摄影署名、地图与图表的编号在同一层完成。
5. **印前与验收**：导出 PDF/X-4 后跑尺寸、字体嵌入、图像有效分辨率、总墨量四项取证；数量化验收改用 `layout-qc`。

## 不可妥协的约束

- 官方版位表写的是 `SIZE H×W`：**260×185 表示高 260、宽 185**。新文档永远建"宽 185 × 高 260"，跨页 370×260，3P 拉页 550×260。建反了整本报废。
- 300dpi 是广告素材的最低交付线，**不是排版用图标准**；175 线对应素材系数 ×2 ≈ 350dpi。
- 小字与正文用单色黑 K100 或 K 通道灰，**不要用四色黑**；175 线下四色黑套印必出虚边。
- 跨页图与拉页折线两侧各留 10mm 安全区：胶装会吃掉订口 3–5mm 且跨页摊不平，人脸、地图标注、人名落进去就是事故。

## 封面规则（每期只换图与文字，不动版式）

- 四边红色边框是刊物身份识别，宽度约为封面宽的 7.5–10%；红色**用印刷色标定义**，不要从网上 JPG 取色。
- 图与品牌色**必须做色相/明度分离检查**：主图偏红橙时红框会"消失"，此时换图或压低主图饱和度。
- **底色明度决定字色**：暗底用白字、亮底用深字。白字压亮冰面/亮天空是最常见事故，每期定稿前做一次灰度打印检查。
- 家具位置锁定：刊名带（距顶约 12%、高约 10%）、右上期号信息块、左下条码框、底部 5–6 组要目。**期号/年份/价格在母版里只定义一次**，所有位置引用同一变量。

## 排版决策速查

- 版面密度高但秩序强：一页之内允许"通栏大图 + 小栏正文 + 侧栏图注"混排，混排靠栅格对齐，不靠人工挪。
- 每期只允许一个强调色，且强调色从主图已有的颜色里取。
- 标题优先落在画面暗部；同色系相邻时靠投影或压暗分离，不靠描边。
- 栏目识别靠统一的标题样式 + 栏目标识，不靠每期换花样；特别策划可以单独设计标识，但正文样式不变。
- 广告位（版权对页、目录对页、跨页、封三封底）在母版阶段占位，正文不要事后挤压。
