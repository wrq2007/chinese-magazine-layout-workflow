# 生产与印前规格

数值来自《中国国家地理》官方广告刊例（2021 版，`dili360.com/public/ads/2021ad.pdf`）以及由该刊例推导的落地值。

## 1. 官方规格（刊例原文核实）

| 项目 | 官方值 |
|---|---|
| 物料尺寸 | 单页/全页 260×185（H×W）；跨页 2P 260×370；封面拉页 2P 260×364；内页拉页 3P 260×550 |
| 出血 | 各边 3mm |
| 色彩模式 | CMYK |
| 印刷装订 | 四色胶装 |
| 网线 | 175 lpi |
| 分辨率 | 300dpi（**广告素材最低交付线**） |

刊例里的版位分类本身就是一份刊物结构图：封面拉页 → 卷首前跨页 → 卷首对页 → 第一至第六跨页 → 第一/第二版权对页 → 第一至第三目录对页 → 普通目录对页 → 封选/行动对页 → 普通跨页 → 前 1/2 全页 → 普通全页 → 封三 → 封底。可见**前 40–50 页以广告与前置页为主，正文从目录之后开始**；做自有刊物时应在母版阶段就把这些版位固定下来。

刊例中另有两处自相矛盾，签版位前要书面确认：3P 拉页的图示标 370mm 而价目表写 260×550；"卷首前跨页（FOREWORD DPS）"的规格列写的是单页 260×185。

## 2. 文档设置

- 文档尺寸 **185（宽）× 260（高）mm**，对页，页数取 **16 的倍数**（128/144/160）。
- 出血 3mm → 含出血单页 **191×266mm**，跨页 **376×266mm**（只在左右外沿加，中缝不加）。
- 封面拉页 370×266mm；3P 拉页 556×266mm。
- 胶装页数须为 4 的倍数，拼版按 16 页/帖最省。

## 4. 色彩与网线

- 文档 CMYK，配置文件 `ISO Coated v2 (ECI)` 或 `Japan Color 2001 Coated`（175 线涂布纸）；不做两次转换。
- 总墨量 TAC ≤ 300%（涂布纸）/ ≤ 280%（轻涂、胶版纸）。
- 正文与小字用**单色黑 K100**；大面积黑可用 C60 M40 Y40 K100，但四色黑不得用于小字（175 线套印必出虚边）。
- 灰度图走 K 通道，不要用四色叠灰。
- 175 线下平网最浅不低于 8%；避免大面积 15–25% 的"脏灰带"。
- 深色满版底 + 白字是常见需求，但要注意总墨量与露白；深底白字建议字号 ≥ 10pt。

## 5. 导出与印前取证

导出 **PDF/X-4**，标准设置：出血 3mm + 裁切标记；图像不降采样，有效分辨率 ≥ 300dpi（按实际摆放尺寸复核）；字体全部嵌入；不做色彩转换（No Color Conversion）。

逐项取证，**每一项都要有截图或数值证据**：

1. 页面尺寸与出血（单页 191×266、跨页 376×266）。
2. 字体嵌入列表（无缺字、无替代）。
3. 图像有效分辨率报告（低于 300dpi 的逐一列出，说明是故意放大还是漏改）。
4. 总墨量报告（TAC ≤ 300%）。
5. 黑色文字是否单色黑；小字是否误用四色黑。
6. 跨页图/拉页折线两侧 10mm 安全区内是否有关键信息。
7. 页码与目录页码是否一致（含广告页是否计入页序）。

## 6. 胶装与折页专项

- 订口会吃掉 3–5mm 且跨页摊不平：跨页图与拉页折线两侧各留 **10mm 安全区**，人脸、地图标注、人名不要落进去。
- 封面拉页的折进页窄 6mm（185 + 179 = 364），靠折线 10mm 内不放关键信息。
- 3P 拉页每折约 183.3mm，折线 ±5mm 内不放内容。
- 满版图必须自带 3mm 出血，不能靠"拖大一点点"充数。

## 7. 常见坑

1. **`260×185` 是"高×宽"**。刊例列头写 `SIZE H×W`。新建文档一律宽 185 × 高 260；把 260 当宽度建出来的稿整本横竖颠倒。另：**"对页"= 单页满版（185 宽）**，不是跨页。
2. **300dpi 不是排版用图标准**，是广告素材的交付下限；175 线按 350dpi 备料，且必须按最终摆放尺寸核算像素。
3. **刊例自身有数字冲突**（3P 拉页、卷首前跨页），签版位前书面确认，不要照抄图示。
