# 版式系统（185×260mm）

## 1. 栅格数学

版心 = 开本 − 边距。默认 `上18 / 下22 / 内20 / 外16` → **149 × 220 mm**。

基准 **6 栏**：

```
19 × 6 + 7 × 5 = 149  ✓   （栏宽 19mm，栏距 7mm）
```

从 6 栏组合出的常用宽度：

| 用途 | 组合 | 净宽 | 说明 |
|---|---|---|---|
| 正文 3 栏 | 2+2+2 栏合并 | 45mm | 密集信息、短稿、栏目页 |
| 特稿 2 栏 | 3+3 栏合并 | 71mm | 长稿正文，约 21 字/行 |
| 单栏正文（大图页） | 4 栏合并 | 97mm | 约 29–30 字/行，最舒服 |
| 侧栏 / 图注栏 | 1 栏 | 19mm | 只放短标签、编号、竖排词 |
| 通栏图 | 6 栏 | 149mm | 或直接出血到 185mm |

版心高 220mm，基线网格 **14pt ≈ 4.938mm → 44 行**。正文行距取 14pt 时，一页整栏正文 ≈ 44 行。

> 边界：内 20 / 外 16 是给胶装订口留的补偿。若改成骑马订，内边距可减到 17–18mm。

## 2. 字号阶梯（中文，175 线涂布纸）

| 元素 | 字体族 | 字号 / 行距 | 其他 |
|---|---|---|---|
| 正文 | 宋体（思源宋体 / 方正书宋） | 9pt / 14pt | 首行缩进 2 字，标点挤压 + 避头尾 |
| 长特稿正文 | 同上 | 9pt / 15pt | 两栏时用，增加透气 |
| 导语 deck | 宋体或仿宋 | 11.5pt / 18pt | 与标题同宽轴 |
| 引文 pull quote | 粗宋 | 12pt / 18pt | 单独成块，不与正文同栏 |
| 一级标题 | 粗黑体 | 16pt / 22pt | 上空 1 行、下空 0.5 行 |
| 二级标题 | 黑体 | 12pt / 17pt | 与上文空 0.5 行 |
| 封面故事大标题 | 超粗黑体或超粗宋 | 24–32pt / 32–38pt | 主副题可同字号、用颜色分层 |
| 图注 caption | 黑体或宋体 | 8.5pt / 12pt | 与图距 2–3mm |
| 页眉 / 栏目名 | 黑体 | 7.5pt | 与正文同色或 70% 黑 |
| 页码 folio | 数字体 | 7.5pt | 外下角 |

字重对比不必很强：《中国国家地理》内页的层级主要靠**字号 + 位置 + 留白**拉开，标题与正文常同族不同字号。若自行加字重，控制在两级以内。

## 3. 段落与对象样式清单

在 InDesign 里一次建好，之后每期复用：

**段落样式**：正文/正文-两栏、正文-首段、导语、引文、一级标题、二级标题、图注、图注-源、栏目名、页眉、页码、署名（撰文/摄影）、广告位提示。

**字符样式**：数字与西文（与中文搭配的西文单独指定，避免中文字体的西文默认字形）、强调（颜色或字重）、单位与符号。

**对象样式**：整版图（出血 3mm）、跨页图（中缝不解组）、拼版图组（白缝 2–3mm，无描边/圆角/投影）、图注框、色块标签、竖色带。

**母版**：

- `A-正文`：页码 + 页眉 + 6 栏网格 + 基线网格
- `B-专题跨页`：无页眉，仅页码；跨页图出血到 376×266mm
- `C-目录`：目录专用网格（可在 6 栏基础上做 4 栏）
- `D-广告/整版`：185×260，出血 3mm，无页码
- `E-拉页`：550×260（3P）或 370×266（封面拉页），折线两侧 10mm 安全区

## 4. 内页图文关系（跨页密度节奏）

有效跨页的常见骨架是**三段式垂直节奏**：

```
上方图带（1/4–1/3 页高，拼版图组或单张通栏）
中部文字块（白底或压图白块，标题居中 + 导语 + 单栏正文）
下方大图（接近 1/2 页高，下出血或右出血）
```

两个跨页之间的"疏密对照"比单个跨页内部的装饰更重要：一页做**拼版小图组**（信息密集），对页做**单张全幅图**（视觉冲击），读者翻页才有节奏。

**白块压图**是可迁移性最强的一手：把正文放进压在全幅照片上的白色矩形里，图仍然满版，文字不牺牲可读性。前提是白块四边留足 5% 页宽的缓冲，否则换图即崩。

## 5. 图注与图号系统（必须补齐的一项）

参考刊例里的版式实样**没有图注、没有页码、没有页眉**，那是"示版稿"而不是成品页。做真刊时必须建立：

- 每张图**必须有图注**：说明性文字 8.5pt + 独立一行出处（`摄影/XXX`、`供图/XXX`、`制图/XXX`）。
- 图注位置统一：图下 2–3mm，宽度与该图等宽，不与正文混排在同一栏里。
- 图号系统：`图1`、`图2`…贯穿全刊或按文章编号（`图1-3`）；正文中引用图号。
- **图与相关正文尽量落在同一跨页或相邻 2 页内**。跨页引用时写"见第 X 页图 3"——这是圈内对《中国国家地理》最集中的批评点（图和文分离，读者要不停回翻），做自有刊物时反过来用。
- 地图、剖面图、示意图必须标注：图名、比例尺或方向、资料来源。

## 6. 封面母版清单

| 母版元素 | 位置（占封面比例） | 锁定内容 |
|---|---|---|
| 品牌色边框 | 左右 7.5–10% 宽，上下 6–7% 高 | 印刷色标定义，不从 JPG 取色 |
| 刊名带 | 距顶约 12%，高约 10%，占宽 82–88% | 字族、白字、字号、位置永不变 |
| 期号信息块 | 右上，封面高 3–9% | 左列年份/总第X期/大号期号；右列价格/刊号/邮发代号/网址，中间 0.5pt 细白竖线 |
| 条码框 | 左下 | 白底，ISSN + 条形码 + 期号角标 |
| 封面故事 | "封面"标签右上或左上；"主打"标签 + 主标题在下半幅 | 一期只用一种对齐方式 |
| 要目区 | 右下或底部，5–6 组 | 中黑体，题头 + 说明两层靠字重区分，行距约 1.25 |

**可读性规则**：

- 底色明度决定字色——暗底白字、亮底深字；同一封面上允许两种字色，但必须按"底明度"分区判定。
- 标题优先落在画面暗部；必要时压暗或加半透明深色底条，不要用描边。
- 每期只允许一个强调色，且取自主图已有的颜色。
- 主图与品牌色做色相/明度分离检查：主图偏红橙时色框会消失。
- 定稿前做一次**灰度打印检查**（小字、期号、价格最容易失效）。

## 7. 栏目页模板

栏目页是"每期结构相同、只换内容"的页型，做 3–5 个模板即可覆盖整本刊：

- **卷首语页**：整页文字 + 一张小图或通栏图带，署名与栏目名固定位置。
- **单一栏目页**（原产地、经典栏目等）：1 栏图片区 + 2 栏正文，页眉带栏目名与期号。
- **专题首页**：大图出血 + 居中标题 + 导语，页码照常。
- **专题内页**：见第 4 节三段式骨架。
- **图集/跨页图**：无页眉，仅页码；图注统一在图下或图侧。

模板里固定的东西越多，每期的排期与成本越可控。
