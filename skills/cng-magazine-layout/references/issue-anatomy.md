# 整期结构与页数分配

## 1. 栏目体系（源自官方刊例的"呈现形式"与"经典栏目"）

官方把内容分成两类呈现形式：

- **地域专辑**：以行政或自然区划为单位，综合报道某地区的自然、人文、历史（如云南、西藏、新疆、大香格里拉）。适合用整期或半期做。
- **地理专题**：追踪社会热点、难点、疑点背后的地理背景，深入报道某一地理事物或现象（如三峡、选美中国、青藏铁路、沙尘暴、科考探险）。

常规栏目名（可直接借用或改造）：**卷首语、封面选择（封面故事）、原产地、经典栏目、民族专题系列、自然与文化遗产、科考探险、另类摄影、寻找桃花源、考古文明、社会热点的地理解析**。

编辑部的内容规范是 **"三精 + 三图"**：文章精准、精彩、精炼；表现形式同时使用图片、图表、插图。这条规范直接决定版面必须给图表和插图留位置，不能只有照片。

## 3. 页数分配规则

- 先定总页数（16 的倍数），再按"专题 : 栏目 : 广告 : 前置后置 ≈ 40 : 40 : 15 : 5"分块，最后才排单页。
- 广告与前置页占前 40–50 页是**行业常态**（官方刊例的版位序列就是从封面拉页一路排到目录对页），正文从目录之后开始，做版式时不要被"前 12 页都是广告"打乱页码节奏。
- 广告位在母版阶段占位并按固定版位编号（封面拉页 / 卷首前跨页 / 第 N 跨页 / 目录对页 / 封三 / 封底），正文排版时不再挪动。
- 单页与跨页交替：连续 3 页以上纯文字页必须打散，插入图版或图表页。

## 4. 专刊 / 增刊 / 专辑的差异

专辑、特刊常做到 160 页以上且只有一个主题，结构随之变化：

- 取消大部分常规栏目，改为"地理分区 / 时间线 / 专题分章"三选一的主线；
- 目录页扩到 4–6 页，带分区导览地图；
- 增加**拉页**（3P、甚至多折）展示全景照片、地图、剖面图；
- 图表比例显著上升（比例尺地图、剖面图、对比数据图），这正是官方"三图"规范最能发挥的地方；
- 前后置页压缩到最少，广告集中在封二/封三/封底。

## 5. 节奏检查清单

排完整期后，用翻页的方式自查：

1. 有没有连续超过 4 页没有大图或跨页？
2. 有没有两个连续跨页用了同样的骨架（同一种图位 + 文字块）？
3. 每篇稿件的图是否与对应正文落在同一跨页或相邻两页内？
4. 图号是否能顺下来，正文引用是否都有对应图？
5. 广告跨页前后是否刚好是内容高点（读者翻到广告前会先被内容吸引）？
6. 目录页码与正文实际页码是否一致（含广告页是否计入）？
