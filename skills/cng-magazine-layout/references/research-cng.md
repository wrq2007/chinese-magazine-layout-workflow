# 调研纪要：规范、评价与来源

这份文件记录本技能的每一条硬数值从哪里来，以及哪些结论属于推断。**改数值前先看这里的出处。**

## 1. 电子版的官方渠道（重要）

《中国国家地理》的电子版**不在官网公开下载**，官方渠道是微信小程序 **「中国国家地理畅读」**：上架《中国国家地理》2001 年第 1 期至今、《中华遗产》2008 年第 3 期至今、《博物》2004 年创刊号至今，以及增附刊、英文版、《行天下》旅行版。官方另有"中国国家地理客户端"App（多屏阅读，购买后阅读）。

也就是说：**不存在可合法整本下载 PDF 的免费渠道**。做版式研究时应当走"官方试读 + 官方刊例规格 + 公开可索引的封面与内页图"这条路径，而不是找盗版 PDF。

纸质端的当前进度可查官方商城 `store.dili360.com/category.php?id=3`（截至调研时上架到 2026 年 07 月，订阅渠道显示已更新至 8 月期）。

## 2. 已核实的官方规范

来源：官方广告刊例 PDF（2021 版）。

- 物料尺寸 260×185（H×W）、跨页 260×370、封面拉页 260×364、内页拉页 3P 260×550；出血各边 3mm；CMYK；四色胶装；网线 175；分辨率 300dpi。
- 版位序列（封面拉页 → 卷首前跨页 → 卷首对页 → 第一至第六跨页 → 版权对页 → 目录对页 → 封选/行动对页 → 普通跨页 → 普通全页 → 封三 → 封底）说明广告与前置页集中在刊首。
- 内容规范："三精"（精准、精彩、精炼）+"三图"（图片、图表、插图），科学性要与艺术性统一。
- 呈现形式：地域专辑 / 地理专题；经典栏目：卷首语、封面选择、原产地、经典栏目、民族专题系列、自然与文化遗产、科考探险、另类摄影、寻找桃花源、考古文明、社会热点的地理解析。
- 刊例内部有两个数字冲突（3P 拉页的图示 vs 价目表；"卷首前跨页 FOREWORD DPS"的规格列写单页），已在 `production-specs.md` 标为需二次确认项。

来源：官网"封面选择"栏目（cng.dili360.com 的 zzfm 系列文章，记录了 2011–2016 年各期封面评选过程）。

- 封面不是单人决定：编辑部从十几张候选里选出 4 张备选，经几轮投票与评点后定稿。淘汰理由通常是"缺乏冲击力""色彩略显斑驳"这类可量化的视觉判断。
- 结论：**封面选片应当流程化、有淘汰理由、留候选记录**，而不是最后一刻拍板。这条已写进 `design-system.md`。

## 3. 视觉分析（由 dsh/DeepSeek 视觉模型对公开图源逐图拆解）

分析对象：公开渠道可索引的《中国国家地理》封面（2022–2025 年多期，含微博"封面选择"候选稿）、官方刊例内页版式实样（拉卜楞寺跨页）、官方刊例物料标准页。**注意：这些结论来自模型对图片的目测与量测，属于参考性证据，不含官方公布的版式参数。**

封面体系（多期一致性很高）：

- 四边红色边框是识别件，左右约占封面宽 7.5–10%，上下约 6–7%；刊名带位于距顶约 12%、高约 10% 处，占宽 82–88%，多期位置几乎完全重合。
- 家具四块固定：刊名带 / 右上期号信息块（左列年份·总第X期·大号期号，右列价格·刊号·邮发代号·网址，中间细白竖线）/ 左下条码白框 / 右下或底部 5–6 组要目。
- 刊名与封面故事主标题用粗字族 + 白字压图，靠硬投影分离；副题常用黄或橙色承担"看点"层级。
- 反复出现的两个缺陷，已写成技能里的硬规则：**白字压在亮底上对比不足**（亮冰面、亮天空）；**主图与品牌红同色系时边框"消失"**（红岩地貌那期）。此外还有候选稿沿用上一期模板导致"信息块写 07、条码写 08"的期号不一致事故。

内页实样（刊例中的跨页示版）：

- 骨架是"上方图带 + 中部白块文字 + 下方大图"的三段式垂直节奏，左页用拼版图组、右页用单张全幅图，形成一密一疏的对照。
- 正文单栏，约 29–30 字/行，行距约为字号的 1.6–1.7 倍；标题居中，两侧用细线夹持；导语居中、紧贴标题。
- 层级主要靠字号与位置，字重对比弱。
- **示版稿没有图注、没有页码、没有页眉页脚**——这两项在技能里被明确列为"必须补齐"，而不是模仿对象。

## 4. 外部评价与批评

正面评价集中在图片与装帧：

- 读者评论（什么值得买等）："装帧设计精美，图片呈现更具有真实感""排版印刷干净"。图片质量与开本带来的临场感是被反复肯定的部分。

批评意见集中在图文关系与阅读效率：

- 知乎讨论「为什么中国国家地理排版让我很不舒服」：核心抱怨是**图和文不在一起，看文章想要看图要不停回翻**。这是整套体系最被诟病的一点，本技能因此把"图与相关正文落在同一跨页或相邻两页""跨页引用写页码图号"写成硬要求。
- 版式设计调查报告类文章（字体之家《国内杂志版面设计的调查报告》等）：指出科技/科普类杂志"几乎只用黑体，不论正文还是标题"，《中国国家地理》即被列为典型；字体选择偏保守，风格统一但缺少字体层面的变化手段。
- CSDN《杂志版面设计解析》等较早的评述认为《中国国家地理》的版面结构"几乎全程仿照《美国国家地理》"——即继承了大开本、大图、通栏的国际化版式语言，但在本地化排版细节（图表、字体、网格精度）上长期偏弱。
- 另有文章分析其封面是"红色 C 形边框 + 大幅照片"的固定识别系统——稳定性极强，但也意味着封面的创新空间被边框锁死。

对本技能的取舍：

| 借鉴 | 不照搬 |
|---|---|
| 大图主导、跨页密度对照、严格栅格与固定家具 | 示版稿缺席的图注/页码系统 |
| 封面四块家具的绝对稳定 | 白字压亮底的对比失误 |
| 单栏松行距的阅读舒适度 | 图文分离导致的回翻 |
| 栏目体系与"三图"规范 | 版位混乱或事后挤压正文 |

## 5. 美国《National Geographic》的处理

按用户指示，美国版未做材料采集。仅记录一条公开信息供对照：该刊 2018 年（创刊 130 周年）由内部创意总监 Emmet Smith 与咨询公司 Godfrey Dadich Partners 合作改版，主题是"用视觉讲故事"，重排了内容板块并重做字体。若后续要做中美版式对比，再从该刊官方渠道与设计媒体报道另行取证。
