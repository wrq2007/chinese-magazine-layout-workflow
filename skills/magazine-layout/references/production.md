# 印前与交付

## 交付前清单

**尺寸与出血**

- 页面尺寸与印厂要求一致（含出血 3mm，或印厂指定值）
- 重要内容距裁切线 ≥5mm；跨页图左右出血连续
- 页码、页眉位置逐页一致（用母版保证）

**图像**

- 分辨率 ≥300ppi（按实际放置尺寸）
- 全部链接有效、无丢失；图像色彩模式为 CMYK（或按印厂要求）
- 深色大面积图像注意总墨量（避免四色黑堆到 300%+）

**字体**

- 全部字体可嵌入且已嵌入（PDF 导出勾选嵌入）
- **验证字体真的生效**：导出 PDF → 读内嵌字体名，避免静默回退
  （`layout-qc/scripts/list-pdf-fonts.ps1`）

**色彩**

- 印刷用 CMYK；专色单独标注
- RGB 高饱和色直接转印会发灰，需预先转换并校色

**结构**

- 目录页码与内文实际页码一致
- 页数为装订要求的倍数
- 无空白误页、无错序、无重复页

## 输出格式

- 印刷交付通常用 **PDF/X-4**（或印厂指定标准），字体嵌入、图像压缩设置按印厂要求
- **导出必须带出血**：InDesign 里 `app.pdfExportPreferences.useDocumentBleedWithPDF = true`，
  否则 PDF 的 TrimBox = MediaBox，印厂裁切公差会露白边（实测踩过：0mm 出血的满版封面）。
- 保留可编辑的源文件与链接图，交付 PDF 只是最终形态
- 文件名带版本与日期（刊物常有 v1/v2/终稿多轮）

## 文案长度与版面的匹配

排之前先估：**栏容量 ≈ 每行字数 × 行数**。以 A4 三栏、正文 10.5pt/18pt 为例，
每栏约 42 行、每行约 22 个汉字 → 单栏 ≈ 900 字，三栏 ≈ 2700 字。
文短于版面不是错误（真实刊物常见末栏留白），但要在排之前知道会剩下多少，
并用引文块、图注、小图把余量收掉，不要让末栏空一半还以为"没排完"。

## 拼版常识

- 拼版由印厂按折手完成；设计端只需保证单页尺寸、出血、页序正确。
- 骑马订厚刊会有"爬移"（中缝处页面外移），印厂可能要求做爬移补偿——设计端要预留内白边余量。
- 封面通常是"封面+封底+书脊"连版，书脊宽度取决于页数与纸张克重，需印厂给出的实测值。
