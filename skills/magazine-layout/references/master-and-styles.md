# 母版、样式与网格

## 母版体系

- **基础母版**：页码、页眉/页脚、基本边距参考线。全书共用。
- **章节母版**：章节首页（无页眉、标题区更大）、图版页（无页眉）、广告页等特殊版式。
- 母版上放页码时用**自动页码符号**，不要手打数字——手打页码在增删页后必然错。
- 母版里的页眉文字用"章节标题"变量或直接写固定内容；需要逐章变化时建多个母版。
- 改母版 = 改全书。改前先确认受影响页数（在 InDesign 里可以看母版被哪些页应用）。

## 段落样式命名（建议）

用"用途 + 层级"命名，避免"标题1/标题2"这种无语义名字：

```
正文 / 正文-首段 / 正文-引文
标题-篇名 / 标题-一级 / 标题-二级 / 标题-三级
图注 / 表注 / 图注-来源
页眉 / 页脚 / 页码
导语 / 引言 / 署名 / 数据标签
```

规范：

- 所有文字都套样式，不手动改选中文字的字号/行距（会产生"样式外属性"，改样式时无效）。
- 字号阶梯统一在样式里定义（用固定比例，如 1.25），不要在页面上临时决定。
- 中英文分别设置字体（中文用中文字体，西文/数字用西文字体）。

## 网格与基线

- 先定栏数与栏间距（中文刊物常见 2–3 栏，栏间距 = 正文 1–2 个字宽）。
- 建立基线网格，正文行距 = 基线单位；标题、图注的高度尽量取整数倍。
- 图片顶线/底线对齐到栏或基线，避免"看起来差不多"。

## 文章流

- 一篇文章排成**一条文本流**，跨页、跨栏自动续排。
- 用 InDesign 的文本框链（`nextTextFrame`）或"置入 + 自动排文"。
- 不要用空行、空格、手动换页来"推"版面——那会让后续修改全部崩掉。
- 断行控制：设置孤行寡行控制、标题不与后文分离、避头尾规则。

## 常见错误

1. 手打页码 → 改版后页码全错
2. 母版上放实际内容（正文）而不是版式元素 → 无法逐页修改
3. 复制粘贴文字带来样式外属性 → 全书风格不统一
4. 每页单独建文本框，文章被切成碎片 → 改一个字就要手动重排多页
5. 图片手动缩放对齐 → 换图后全部错位
