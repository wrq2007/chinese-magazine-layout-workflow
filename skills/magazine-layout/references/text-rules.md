# 内容层排印规范（标题 / 正文 / 图注 / 数字 / 标点 / 断行）

规格（开本、版心、字号）以 `cng-magazine-layout` 为准并可随时调整；
**这一份管的是内容层面**——同样内容排出来"像不像正规刊物"，差别都在这里。

## 1. 标题

- 标题**不以标点结尾**（疑问、感叹除外）；标题内部不用句号。
- 标题尽量**整行不拆**：短语/口号用不换行处理或手工断成两行并保持语义完整（"启程西北，/ 共赴新章"可以，"启程西 / 北，共赴新章"不行）。
- 层级用**字号 + 位置 + 留白**拉开（同族不同字号最常见），字重对比控制在两级以内。
- 一级标题上空 1 行、下空 0.5 行；二级标题与上文空 0.5 行。正文与标题**同宽轴**（左边界对齐）。

## 2. 正文

- 首行缩进 **2 字符**；或段间空半行——**二者择一，不得叠用**。
- 行长 **25–35 汉字**；段末不出现**孤字成行**（一行只剩 1 个字），必要时微调字距或断行位置。
- 中西文之间用自动间距（≤ 1/4 汉字宽），**不手打空格**；西文在行首行尾不加空白。
- 段首不排标点；连续段落之间不做空行，避免版面被"打碎"。

## 3. 标点（中文排印高频错处）

- 中文用**全角标点**：，。、；：？！（）《》「」“”……
- 破折号用 **——**（两个相连）；省略号用 **……**（两个三连点）。**不得用一个 `—` 或 `...`**。
- 引号用成对弯引号 “ ”；书名用《》，篇名用〈〉；括号中文用（）英文用 ()，**不混用**。
- 数字与西文用半角；**中文句子里的逗号句号必须是全角**（半角 `,` 只出现在数字/英文里）。
- 避头尾逐行校验：行首不得是 `，。、；：？！）】》」』”’…—·`，行尾不得是 `（【《「『“‘`。

## 4. 数字、年代与单位

- 数字与西文单独指定西文字体（比中文小 0.5pt 视觉重量才相当）；**`&` 不按西文处理**（否则会被自动间距撑开）。
- 年代与日期：卷首/正文里统一一种写法（`2025年10月18日` 或 `2025.10.18`），**全篇不要混**。
- 数量与单位之间不加空格（`20mm`、`9pt`、`175线`）；数值范围用 `–`（短横）不混用 `-`。
- 序数、届别、班级等与汉字之间保持中西文自动间距，不要手打空格凑。

## 5. 图注与图片

- 图注与图**必须同页**，不允许图注被挤到下一页。
- **图片按原生比例缩放，不做非等比拉伸**；大图缩到栏宽要检查有效分辨率，小图不要放大到模糊。
- 图注格式全刊统一：编号（图 01 / 图 1）+ 竖线或空格 + 说明；同一期只用一种格式。
- 图注字号比正文小 1–2pt（如正文 9pt → 图注 8.5pt），与图的间距 2–3mm。
- 图注句式避免以"本图"开头；写明**是什么、在哪里、什么时候**，不写形容词。
- 摄影/撰文署名与图注同一层，用间隔号连接（`摄影 · 张三`）。
- **没有说明就不要硬造图注**：空图注宁可不写，也不要编一句"如图可见"。

## 5.5 强调配给与多期一致性

- 强调按额度给：**锚点层（最强的一处）每页 ≤5 处**，标记层每段 1–3 处，其余靠字号与位置。
  到处加粗等于没有重点。
- **风格锁定**：首期先定一份"金样"（母版 + 样式 + 栅格 + 图表色板），后续各期**照抄参数、只换内容**；
  每期只允许一处"签名细节"变化。这样半年后翻回去仍是同一本刊物。
- 目录页是**精选不是全量**：只放 3–5 个核心看点，不要把全部章节硬塞进去。

## 6. 署名与落款

- 三级递减：**姓名**（最大）→ **单位 + 职务** → **班级/日期**（最小最弱），右对齐；档差 ≥1.25 倍。
- 同一块的色温与底一致（冷底上用冷中性灰阶，不要用暖金）。
- 并列信息用间隔号 `·`（前后不加空格），不用全角空格硬撑。

## 7. 断行与跨页

- 标题、图注、署名**不跨页断开**；跨页处的正文断行要保证两页都不断在段首单字行。
- 跨页图在中缝处必须连续；中缝两侧各 10mm 内不放关键信息（人脸、标注、人名）。
- 每页至少 2 行正文或完整一块图文单元；避免"页脚孤行"（一段的最后一行单独留在页首）。

## 8. 文本不变式与交付前检查

**文本只复制粘贴，不改一个字。** 正文一律由脚本从源文件读入（`extract-text.py` → 段落数组 → 版式引擎），
排版过程中：

- **不增加**任何字（不加"编者按""据了解"这类过渡语）；
- **不删除**任何字（不因版面紧张删句、不合并段落）；
- **不修改**任何字符：标点（逗号/顿号/引号/破折号/省略号）、数字、空格、`&` 之类的特殊符号一律照抄；
- 需要改内容时**先问用户**，拿到明确答复再改。

守住这条不变式，文本就不需要事后逐字比对。排版层面只跑一项机械检查：

```
layout-qc/scripts/check-cjk-typography.jsx   # 避头尾 / 标点配对 / 中西文字体 / 行宽 / 缩进
```
