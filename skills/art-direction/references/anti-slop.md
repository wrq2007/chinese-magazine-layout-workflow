# 去 AI 味（anti-slop）

## 什么是 slop，为什么要反

AI slop = 训练语料里最常见的"视觉最大公约数"：紫渐变、emoji 当图标、圆角卡片+左侧彩色描边、居中大标题+三张一样的卡。

它们不是本身丑，而是**不携带任何品牌/内容信息**——产出等于把所有品牌平均了一遍。反 slop 不是审美洁癖，是保护识别度。

## 什么时候可以破例

**唯一合法理由：品牌/内容本身就是这样。** 品牌规范里写了紫渐变，那它就是品牌签名，不是 slop。
另外注意别误杀"有作者意图的极端风格"：电影级暗调、暖色赛博、运动诗学的暗场叙事都不在禁区——它们携带强烈风格信息。

## 清单（带为什么）

| 元素 | 为什么是 slop | 印刷版对应表现 |
| --- | --- | --- |
| 紫蓝渐变当"科技感" | 通用万能公式，无信息量 | 封面用廉价渐变铺底 |
| emoji 当图标 | "不够专业就用 emoji 凑" | 标题旁挂 emoji 做装饰 |
| 圆角卡片 + 左侧彩色描边 | 某时期模板烂大街组合 | 信息框一律圆角+左色条 |
| 居中大标题 + 等分三栏 | 模板结构，没有阅读顺序 | 杂志内页三栏等分、无主次 |
| 用系统默认字体当展示字 | 读者看不出"设计过" | 标题用宋体/微软雅黑默认字重 |
| 发光/阴影/模糊伪造高级感 | 装饰替代结构 | 印刷里变成脏阴影、糊边 |
| 编造内容填满版面 | 空话、假数据、假 logo | 假图注、凑字数、伪统计 |
| 手画 SVG 代替真实素材 | AI 画的图形比例永远可疑 | 用劣质重绘代替真实产品图/校徽 |
| 均匀用力 | 没有重点 | 每页都同样热闹，翻完整本没记忆点 |

## 正向做法

- **品牌/具名对象必须用真实资产**：出现一个能被认出的品牌、产品、机构，就要取它的真实标识；没拿到就留清晰占位并说明"待补"。
- 文案写具体的：禁"赋能/无缝/颠覆/极致"这类空话；中文用「」而不是 ""。
- 不凭空发明颜色：从既有素材（照片、品牌色、场地色）里取色。
- 一个细节做到 120%，其余 80%。
- 演示反例时用**隔离容器**（虚线框 + "反例·不要这样做"角标），别让整页真的变成 slop。

## 印刷类常见翻车

1. 大标题与正文都用默认宋体，全篇无字体层级
2. 中文字体"设了但没生效"（回退到宋体）——务必验证，见 `chinese-type.md`
3. 版心随意、边距各自为政，跨页对不上
4. 用 RGB 高饱和色直接印，成品发灰或溢出
5. 图片分辨率不足（<300ppi）却在成品上看不出来，直到印出来
