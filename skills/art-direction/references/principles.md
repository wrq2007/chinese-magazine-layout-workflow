# 通用审美判断

## 优先级顺序（按此顺序解决，别跳步）

1. 用户要求的范围与成品边界（组件就是组件，别膨胀成整页/整本）
2. 构图与结构平衡
3. 间距节奏与信息密度
4. 字体层级与文字适配
5. 细节工艺（对印刷是：套准、描边、图形精度；对屏幕是组件精度）
6. 交互状态与行为（仅屏幕）
7. 色彩系统与语义克制
8. 深度线索（边框、阴影、模糊、高光——**印刷基本不用，屏幕要克制**）
9. 动效与反馈（仅屏幕）

判据：**如果灰度打印/灰度截图下不成立，就还没解决结构。**

## 层级

**从尺度取值，不要临时拍。** 业余感的最大来源，是到处用"临时值"（17pt、`#3B82F6`、间距 13mm）。
先把尺度定下来，之后只允许从尺度里挑。

```
间距尺度（相邻值至少差 ~25%，这样选择一眼可辨，不会在 120 和 124 之间纠结）
4  8  12  16  24  32  48  64  96  128  192  （mm 版按比例换算：1 / 2 / 3 / 4 / 6 / 8 / 12 / 16 / 24…）

字号阶梯（印刷用中文常见号数，不要算出一堆小数：
小五9 / 五号10.5 / 小四12 / 四号14 / 三号16 / 小三15 / 小二18 / 二号22 / 一号26 / 小初36 / 初号42）
```

**层级主要靠字重与颜色，不只靠字号。** 需要弱化时，用更小的字号或更淡的颜色，
**不要用更细的字重**（细字重在小字和反白时会消失）。

- **字体是主角**：标题要敢于大（相对正文 2–4 倍起步），显示字收紧字距、行距可紧凑；
  正文字距不动、行距放开。层级不够狠，是大多数"看起来不像设计过"的根因。

- 一个版面只允许一个第一层级焦点。第二层级可以有 1–2 个，其余都降到第三层级。
- 层级差要"跨档"：字号差 <15% 会被读成"没对齐"而不是"有层级"。
- 同层级元素必须真正同级——不要一个 24pt 一个 30pt 又都算"三级标题"。
- 用位置做层级比用装饰做层级便宜有效（边栏、留白、缩进）。

## 密度与留白

- 留白是**结构性的**，不是剩下的：先定版心与边距，再放内容。
- 版心外至少留出 1 个"呼吸单位"（通常等于正文行距），否则会显得廉价。
- 密度要跟读物匹配：学术/文献可密，生活方式/影像类要疏；同一本刊物里密度策略要一致。
- 每个区域不要同时出现"多信息 + 多装饰 + 多颜色"，最多占两样。

## 对齐与网格

- 建立**一套**网格（栏数、基线、边距）并在整份成品里复用；跨页尤其明显。
- 所有元素必须贴到同一套隐形线上。肉眼能看出"差不多对齐"就是没对齐。
- 允许有意破格，但破格必须是**一个**，且服务焦点；两个以上破格 = 乱。
- 文本左对齐优先于两端对齐（中文两端对齐需配合标点挤压，否则字距会烂）。

## 对比与节奏

- 对比来自：尺寸、字重、颜色、负空间、方向、质感。同一处不要叠加三种以上。
- 节奏靠"重复 + 变奏"：同版式重复 2–3 次后给一次变奏（通栏图、跨页、留白页）。
- 稳定的对称与有意的非对称都可成立；**为了不显得模板化而强行非对称**是最常见的败笔。
- **尺度对比**：极小标签 + 极大标题，比"标题大一点、标签小一点"有效得多。

## 强调要有配给制

到处加粗 = 没有重点。给强调分配额度，超了就删：

| 层级 | 放什么 | 额度 |
| --- | --- | --- |
| 锚点 | 本篇最强的一处：核心金句、关键数据、行动点 | **全页 ≤5 处**（跨页 ≤8 处） |
| 标记 | 正文关键词、专名、术语 | 每段 1–3 处，可用加粗或色块 |
| 容器 | 引文、概念标签、长句强调 | 按需，但同一页不超过两层容器 |

**每件成品只加一个"签名细节"**（一处特别的处理：一条金线、一个超大页码、一处破格叠压）。
它是一个，不是很多个——多了就不叫签名。

## 有意断网格

标准等分网格（3 等分、4 等分）天然显得模板化。要"高级"，用可控的破坏：

- **非对称分栏**：2 栏但一栏是另一栏的 2 倍；或 7 栏制，内容跨 3+4。
- **留白的极端化**：某个区域 60% 是空白，内容压在一角。
- **越界叠压**：元素有意压出容器边界（印刷对应出血裁切，屏幕对应跳出容器）。

**拿不准时的两个动作**：减一栏，或者加留白。二选一通常都对。

## 色彩逻辑

- 先定中性色（背景/文字/分割），再定一个强调色；强调色只出现在需要被看见的地方。
- 强调色出现次数与它的作用成反比——到处都是强调色 = 没有强调色。
- **底色与字色都不用纯黑纯白**：用暖/冷的近白（如 #F7F5F1）与近黑（如 #0A0908、#1A1A1A）。
  纯 #000/#FFF 会让整页显得廉价、也更容易在印刷上死黑或过曝。
- 强调色优先取"有材料感的颜色"（赤陶、深棕、黄铜、香槟），少用霓虹与科技紫蓝。
- 小心"廉价高级感"捷径：奶油白/米色打底 + 高饱和强调，容易显得像模板。
- 印刷要单独检查：CMYK 四色黑总墨量、深色渐变条带、专色与四色的混用。
- **用"色相 + 明度"的思维配色，不要各调各的**：同一色相下取 2–3 档明度（浅底/主体/深压），
  比五个互不相关的颜色更容易显得专业。中性灰也要成套（浅灰底、中灰线、深灰字），不要临时调灰。
- 尺度的纪律同样适用于颜色与描边：**描边宽度、圆角、图注间距全篇统一**，不要一页一个样。

## 评审与整改

评审输出必须**先结构后细节**，每条给可直接执行的修正：

1. 最大的结构问题是什么（层级/密度/对齐/焦点/色彩逻辑/工艺）
2. 它损害了什么（可读性、信任感、焦点、行动清晰度）
3. 具体怎么改（改字号/改栏数/删掉哪个元素/换哪一层级），不要说"再精致一点"

整改按 `轻度打磨 → 中等重构 → 重做` 定级，并先说明定级再动手。
