# 中文字体与中英混排

## 授权分级（先合规，再谈审美）

| 级别 | 含义 | 商用可用性 |
| --- | --- | --- |
| T0 开源 | OFL / Apache 等，可自由商用、可嵌入 | 出版物、App 内嵌、转售级安全 |
| T1 厂商免费商用 | 厂商书面承诺免费商用 | 常规商用可用，注意不可转售字库本体 |
| T2 需购买授权 | 方正/汉仪/蒙纳等商业字库 | 必须购买；出版物按发行量计费 |

涉及时政/机构/品牌物料时，字体授权是**合规问题**不是审美问题——不确定就标注风险，绝不含糊带过。

## 场景 × 气质选字（简版矩阵）

| 场景 | 标题字 | 正文字 | 备注 |
| --- | --- | --- | --- |
| 高校/政务/严肃 | 粗黑体（思源黑 Heavy / 得意黑慎用） | 宋体（思源宋/书宋） | 大字用黑、小字用宋最稳 |
| 生活方式/人文 | 衬线或楷（思源宋、霞鹜文楷） | 思源宋/书宋 | 留白要大，字号可偏大 |
| 商业/专业 | 无衬线黑体 | 黑体或宋体 | 数字换西文字体 |
| 儿童/轻松 | 圆黑、手写 | 圆黑 | 避免用宋体做正文 |
| 海报标题 | 得意黑/未来荧黑/思源黑 Heavy | — | 标题字重与正文拉开两档以上 |

## 中英混排规则

- 中文为主（>80%）时，**西文字体服从中文气质**，不能反过来。
- 西文不要用系统默认的 Times/Arial 混排，选字面率接近的西文（如 Inter、Roboto 与中黑体气质接近；衬线中文配衬线西文）。
- 中西文之间加四分之一空（排版软件一般有这个设置），不要手打空格。
- 数字：正文数字建议用西文字体，避免中文全角数字；表格/数据类内容用等宽或表格数字（tabular figures）。

## 字号阶梯与行距（中文）

```
正文 9–10pt / 行距 1.5–1.8 倍 / 行宽 25–35 字
图注 7–8pt / 行距 1.4 倍
小标题 ×1.25  中标题 ×1.5  主标题 ×2–3  封面字 ×4+
```

标题字距收紧 2–4%，正文不收紧。

### 可读性底线（印刷比屏幕更严）

- **字号用号数制思考**：五号 = 10.5pt、小五 = 9pt，都是出版常用正文尺寸。
  杂志（涂布纸 + 175 线）正文 **9pt/14pt 是常规**（《中国国家地理》刊例体系即此值）；
  书籍/散文类可上到 **10.5–11pt**；胶版纸再小会发灰。
- **反白（白字压深色图/色块）要额外加 0.5–1pt**：反白字被网点"吃掉"边角，视觉上比实地黑字更细更小。
  **深底白字建议 ≥10pt，9pt 以下不要反白**。
- **小字不要用 Light / Thin 字重**（眉标、署名、图注、页码）：细笔画在印刷中会断、
  在反白时更会消失。小字一律 Regular 起步。
- 字体自带的拉丁字形往往很差（宋体的数字尤其明显）：**数字与西文要单独换西文字体**
  （Times / Minion 一类），并比中文小 0.5pt 使视觉重量相当。能设置复合字体（复合字型）就设置，
  否则逐字符改 `appliedFont`。
- 行距倍数：文学/散文 1.7–1.9；资讯/说明 1.5–1.7；图注 1.3–1.4。

### 行宽

- **每行 25–35 个汉字**是舒适区；超过 38 字读者会丢行，低于 20 字换行太碎。
- 算行宽：`版心宽度(mm) ÷ (字号pt × 0.3528)`。例：11pt 中文若版心 125mm → 约 32 字 ✓。
- 拿不准就**收窄版心**（加大左右边距），比缩小字号更体面。

### 中西文之间：不多于四分之一个汉字宽

W3C《中文排版需求》(clreq) 原文规定：**汉字与西文字母、阿拉伯数字之间，使用不多于四分之一个汉字宽的字距或空白**；
**西文出现在行首或行尾时不加空白**。操作上就是开启排版软件的中西文自动间距，不要手打空格。

### 禁则处理：先挤进，后推出

clreq 对行首行尾禁则给出的处理顺序（照做即可，不必自己发明规则）：

1. 先做**标点挤压**（把不该在行首的标点挤回前一行）；
2. 挤压无机会时，才把前一行最后一个字**推到下一行**；
3. 前行因此多出的空间按优先级拉伸，最后才用**平均拉大字距**兜底。

另有一条常被忽略的例外：当出现 `。』」` 这类**三个标点连排**时，为避免字距失控，可以放宽禁则。
（来源：W3C《中文排版需求》https://github.com/w3c/clreq）

### 行距

- clreq 对段落行距的基准表述是**行距在字级 1.5 倍以上**；中文正文实践区间 **1.5–1.9 倍**。
- 字号越小，倍数越大（9pt 正文用 1.55–1.7 倍更舒服）。行距一旦定下，全篇保持一致。

### 段落的区分方式（二选一，别叠用）

- 方案 A：**首行缩进 2 字符**，段间不空行 —— 中文书籍/刊物正文的默认做法。
- 方案 B：段间空半行，不缩进 —— 更适合短段落的资讯、访谈、图注。
- 同时缩进又空行 = 段与段的层级关系重复表达，版面显松散。

### 用字要跟文体走

| 文体 | 用字建议 |
| --- | --- |
| 抒情散文 / 序言 / 特稿 | **宋体同族**：标题宋体 + 正文宋体，靠字号与字距拉层级；克制、书卷气 |
| 资讯 / 说明 / 数据 | 黑体标题 + 宋体正文（或黑体正文）：理性、现代 |
| 潮流 / 青年 / 活动 | 黑体标题 + 黑体正文，可用粗字重与大字号 |

判断顺序：**先看文体，再选字族**。一篇抒情序言用"无衬线标题 + 宋体正文"的新闻式组合，
技术上没错，但气质不对。

### 署名（文章末尾的落款）要分级，不要挤成一行

**错误做法**（真实踩过）：把单位、职务、班级、姓名、日期全塞进一两行，用全角空格硬分隔，右对齐后成一条参差的长带，姓名毫无突出。

**规范做法：三级递减，右对齐，每级只放一类信息**

```
（与正文之间留 1–2 行空隙）
                     王锐琪                ← 一级：姓名。最大最重（11pt / 暖白 / 字距 +40）
          动静影像工作社 2023级副社长        ← 二级：单位 + 职务（9.5pt / 弱强调色）
                2023级10班 · 2025.10.18   ← 三级：班级／日期等附属信息（9.5pt / 最弱的灰白）
```

- 三级之间用**字号 + 颜色**同时区分，且档差 **≥1.25 倍**（12 / 9.5 / 8.5pt 比 12/10/9 更能读出层级；
  0.5pt 的差别远看会并成一档）。
- 每级间距**随字号等比递减**（如 5 / 4pt），不要三级都用同一个值，否则末行上方会显松；
  整体与正文之间留 20–30pt（署名是"落款"，不是正文的延续）。
- **色温要与底一致**：压在冷调照片上的小字不要用暖金/米黄（会在冷底上"显脏"）。
  同一块署名用**同一色系的明度分档**（如暖白 → 冷浅灰 → 冷中灰），把强调色留给版面里唯一的分隔线。
- 并列信息用**间隔号 ·**（前后不加空格）连接，不要用全角空格硬撑。
- 期刊文章也可以把姓名提到标题下方（"文 / 王锐琪"），但**文末落款仍需完整**。
- 署名里的数字（届别、班级、日期）同样要换西文字体，并随该级字号自动减 0.5pt。

## 字体必须验证"真的生效"

**回读不等于生效。** 实测：在 InDesign 里把中文标题设为某开源字体，属性回读一切正常，导出 PDF 时却**静默回退**成宋体——外观上还未必立刻看得出来。

验证方式（唯一可靠）：导出 PDF → 读内嵌字体名

```
powershell -ExecutionPolicy Bypass -File <layout-qc>/scripts/list-pdf-fonts.ps1 -Path 成品.pdf
```

本机（Windows + InDesign 21.4.1.4）实测结论：

- ✅ 可用：微软雅黑（Light/Regular/Bold）、等线（Light/Regular/Bold）、黑体、宋体、方正舒体、方正姚体、华文宋体
- ❌ 不可用：`Noto Sans SC (OTF)` 会回退成宋体（系统里这套字体在 InDesign 中不可靠）
- ○ 未测：Noto Serif SC、Source Han Serif SC Heavy、Adobe 宋体 Std

**结论：中文排版优先用微软雅黑/等线；要用思源系，先按上面的方法验证，再决定是否作为生产字体。**

安装新字体后必须重启排版软件，否则字体不会出现在列表里。
