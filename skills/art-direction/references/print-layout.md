# 印刷版式（杂志/画册/海报/物料）

## 先立规矩，再做版面

1. **开本与出血**：正文页出血 3mm（按印厂要求）；重要内容距裁切线 ≥5mm。
2. **版心**：定左右边距（内白边通常略小于外白边，考虑装订吃边）、上下边距、栏数与栏间距。
   栏间距常规 = 正文 1–2 个字宽。
3. **基线网格**：正文行距为基准单位，所有元素高度尽量取基线整数倍——这是"专业感"最便宜来源。
4. **母版与样式**：页眉/页脚/页码/图注位置全部走母版；段落样式统一管理字号、首行缩进、避头尾。

## 字号阶梯（用比例，不要凭感觉）

以正文为基准，用固定比例（如 1.25 或 1.333）生成阶梯，避免"差一点点"的假层级：

```
正文 9–10pt（杂志）→ 图注 7–8pt → 小标题 ×1.25 → 中标题 ×1.5 → 主标题 ×2–3 → 封面字 ×4+
```

- 中文正文行距常规 1.5–1.8 倍字号；字号越小，行距倍数越大。
- 一行正文建议 **25–35 个汉字**；超过 40 字读者会跳行，低于 20 字会频繁换行打断节奏。
- 标题字距收紧（-2% ~ -4%），正文不收紧；数字与西文可用行内微调。

## 中文排印细节

- 标点：中文标点用全角，避头尾必须开启（行首禁 `，。、）】」` 等，行尾禁 `（【「` 等）。
- 中西文之间加**四分之一空**（或使用支持自动间距的设置），不要手打空格。
- 数字与西文用西文字体，汉字用中文字体——分别设置，别指望一个字体全包。
- 首行缩进 2 字符用于连续段落；标题、图注、列表不缩进。

## 图版与图注

- 图注与正文同栏宽、小一号字、常配浅色或上边细线；图注必须与图片同页（跨页是硬伤）。
- 图片按裁切框对齐，不要"看起来差不多"；同页多图必须同一基线或同一顶线。
- 图像分辨率：印刷 ≥300ppi（按实际放置尺寸）。

## 跨页与整本一致性

- 跨页图必须左右出血连续，中缝不留白；跨页文字要避开订口。
- 逐页检查：版心左右边界是否一致、页眉基线是否跳动、页码位置是否统一。
- 目录页码与内文实际页码必须一致（改动后必须重新核对）。
- 章节起始页、空白页、奇偶页安排要符合装订与阅读习惯。

## 印前事故清单（按发生频率）

1. 页面尺寸/单位错（例如把磅当毫米用），导出的成品尺寸整体偏大或偏小
2. 字体未嵌入或"设了没生效"（静默回退），形态与设计稿不符
3. 图片链接丢失或用低分辨率图放大
4. 深色大面积用四色黑、总墨量超限，印出来脏且不干
5. RGB 高饱和色直接转印，成品发灰
6. 出血不足或重要内容压到裁切线

## 交付前

用 `layout-qc` 逐页量测 + 检查 PDF 内嵌字体；不要用"看起来没问题"结案。
