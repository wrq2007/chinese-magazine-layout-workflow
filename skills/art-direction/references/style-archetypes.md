# 风格原型（一次只选一个，选定后服从到底）

从多个开源设计库的几十套风格里，归纳出**可迁移到印刷**的六个原型。它们互斥——混用会同时失去两种气质。

## 1. 极简编辑（Minimal Editorial）

- 特征：中性色 + 单一强调色 + 大留白，为阅读而生；层级全靠字体与间距
- 印刷表达：大版心边距、正文行长偏短、标题与正文对比强、图中留白多
- 适合：文化、学术、生活方式、高端品牌
- 翻车点：留白不足变成"空"；强调色用多变成花

## 2. 工业粗野（Industrial / Brutalist）

- 特征：硬网格、极端字号对比、等宽字、机械感、信息密集
- 印刷表达：通栏大字、栏线可见、表格与数据排版、编号系统明显
- 适合：数据、科技、体育、专题报道
- 翻车点：密到读不动；为了"野"而放弃可读性

## 3. 数据密集（Data-Dense）

- 特征：图表为主，信息高密度，冷静的仪表感
- 印刷表达：信息图跨页、表格与图注体系严密、色彩只用于数据语义
- 适合：财经、年报、行业刊物
- 翻车点：缺乏视觉节奏，整本像报表

## 4. 电影暗调（Cinematic Dark）

- 特征：戏剧性光影、超大标题、深色主导、氛围强
- 印刷表达：满版深色图 + 反白标题；注意总墨量与纸张吸墨
- 适合：影像、时尚、特刊、人物专题
- 翻车点：印成"一团黑"；反白字过细易糊

## 5. 暖色人文（Warm Humanist）

- 特征：暖色纸感 + 衬线字 + 大留白，有人味
- 印刷表达：米白纸感底、衬线标题、较小的正文密度、大量呼吸空间
- 适合：文学、访谈、文化专题
- 翻车点：暖色底 + 低对比文字导致可读性差（印刷比屏幕更明显）

## 6. 大胆彩色（Bold Playful）

- 特征：高饱和、硬边、超大数字、插画感
- 印刷表达：专色或大面积实底、几何构成、字体极重
- 适合：青年、潮流、活动物料
- 翻车点：四色叠印追不上屏幕饱和度；大面积专色成本飙升

## 用法

1. 先按题材、读者、发行场景选**一个**原型。
2. 把原型的特征写进视觉命题（一句话，例如"安静的学术感，靠间距与秩序"）。
3. 全篇服从该命题；需要变化时，用**版式变奏**（通栏大图、留白页）而不是换风格。
4. 若用户明确点名品牌或已有视觉资产，品牌规范优先于本表。

## 附：成品的常见规格（做物料时先定尺寸再动手）

| 用途 | 尺寸 |
| --- | --- |
| 微信朋友圈封面 / 视频号 | 1080×1080 / 1080×1260 |
| 小红书图文卡 | 1242×1656（3:4 常用）、1080×1440 |
| B 站 / YouTube 封面 | 1920×1080（B站 1146×717 安全区） |
| 公众号首图 | 900×383；正文插图 1080 宽 |
| 微博 / Twitter / X 头图 | 1500×500 / 1500×500 |
| LinkedIn 横幅 | 1584×396 |
| Facebook 封面 | 1640×624 |
| 网页 Hero 主视觉 | 1920×1080 起，重点内容留在安全区 |
| A 系印刷品 | A4 210×297、A3 297×420（+3mm 出血） |

**规则**：先定用途与尺寸 → 再定风格原型 → 最后才排版面。顺序颠倒必然返工。

社媒/横幅可用的艺术方向（一次只选一个）：极简、渐变、大字排版为主、照片主导、插画、
几何构成、复古、玻璃拟态、3D、霓虹、双色调、编辑风、拼贴。
