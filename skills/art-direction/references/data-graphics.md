# 数据图、图表与地图（刊物里的说明性图形）

杂志里的图表不是"配图"，是**用图形讲事实**。目标：改善表达，**绝不改动数据本身**。

## 两条判断镜头

- **信号经济**：每个可见的笔画要么编码数据，要么帮助读者解读（轴、刻度、单位、图例）。
  想加装饰前先删装饰；但**轴、比例、误差、参考线不能删**——它们保护解读。
- **视觉诚实**：视觉差异必须跟随数据差异。明度要单调递进，色板要与数据含义匹配，
  不能造出数据里并不存在的分界或重点。

## 上色之前先做结构审计（五类，每类明确 pass / fail）

| 审计项 | 看什么 |
| --- | --- |
| 层级 | 视觉最重的元素是不是焦点数据？标题/图例/标注有没有抢戏 |
| 边框 | 数据范围与轴域是否一致；零基线与共享比较是否需要；空白不等于浪费 |
| 语义 | 单位、归一化、聚合、平滑、插值、不确定度、参考值是否都核对过 |
| 角色 | 每个图层分类为：主体数据 / 上下文 / 结构 / 强调；有没有无关图层用同样的颜色和重量 |
| 脚手架 | 次刻度、网格线、边框、重复标签：是否真的帮助定位或查阅 |

## 色板要与数据语义匹配

| 数据性质 | 该用的色板 |
| --- | --- |
| 名义类目（无顺序） | 几种视觉重量相当、色相可区分的定性色板 |
| 有序／高低值 | **明度单调**的顺序色板（如 viridis / magma / cividis） |
| 围绕有意义的中心变化 | 以该中心规范化的发散色板（**不要因为数据有均值就硬造中点**） |
| 周期性（方向、相位） | 循环色板 |

**避开彩虹色板与 jet**：明度不单调，会造成假边界与误导性强调。
颜色不够区分时，加**第二线索**（线型、标记形状、位置、直接标注）。灰度打印必须仍可辨。

## 标题与标注

- 有证据支持才用"洞见式标题"（"东部增速是西部的两倍"）；否则用**精确的描述性标题**。
- 单位与必要语境放在副题或轴标签里，不要塞进标题。
- 标签能直接标在图上就直标（不遮挡、不裁切的前提下）；密集时退回过紧凑图例。

## 交付前

- 换算到**实际印刷尺寸**检查：最小字号、最细线宽（175 线下细于 0.25pt 的线会丢）、灰度可辨性。
- 图表与正文同源：数字必须与正文一致，改稿后同步更新；图注写明**来源与口径**。
